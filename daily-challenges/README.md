# Week 7 Daily Challenges

This folder contains the five practical challenges from IYF Weekend Academy Season 12, Week 7. Open [index.html](./index.html) with a local development server to try them.

| Day | Challenge | What to practise |
|---|---|---|
| 1 | Theme Persistence | Save a light/dark theme preference and restore it on page load. |
| 2 | Recent Searches | Keep the five latest searches, remove duplicates, and reuse a previous search. |
| 3 | Form Auto-Save | Save a draft every five seconds, restore it after refresh, and clear it after submission. |
| 4 | Refactor Challenge | Validate input, extract responsibilities, use named constants, and handle errors. |
| 5 | Code Review | Review the Week 6 Weather Dashboard and record evidence-based findings. |

The browser stores each challenge's practice data locally. It is not sent to a server.

## Day 5 review target

The review checklist points to the [Week 6 Weather Dashboard repository](https://github.com/Quantums-meruit/iyf-s12-week-06-Quantums-meruit). Check each item only after inspecting the relevant code. The checklist is a worksheet; completing it and writing your own observations is part of the learning task.
